25% Weight • AI Integration Quality services/aiService.js

1. Selective Context Pruning & Graceful Degradation

  • • Selective Policy Context: The API routes the query to one BookLeaf policy section and includes only the referenced book's operational record. It omits the catalogue and previous conversation history from the model request.
  • • Model Choice: The server currently supports OpenAI gpt-4o-mini, configured with OPENAI_API_KEY. The request has a configurable timeout and records provider token usage when returned.
  • • Fallback: With no key or when the provider fails, the server uses deterministic classification and a policy-specific response template, then marks ai_degraded: true for admin review.
glass-interface • Fluid Motion SpringSolver(damping, response)

2. Interface interaction patterns

  • • Zero-Latency Pointer-Down Response: Every button and card responds on pointerdown (scale(0.968)) rather than waiting for click release.
  • • Interruptible Springs & Velocity Handoff: Gesture-driven scrubber and floating PiP interactions use pointer capture, live position updates, release velocity, and reduced-motion fallbacks.
  • • Momentum & Boundaries: The scrubber uses direct pointer tracking and a spring settle; motion and transparency preferences have accessible alternatives.
